# Citadel agent instructions

For Cloudflare deployment, release verification, or deployment troubleshooting, read and follow [the Citadel deployment skill](skills/citadel-deploy/SKILL.md). It documents Lyra's production target, checks, environment selection, and authentication recovery.

Ordinary development does not authorize production deployment. Use the current app configuration and repository scripts as the source of truth; preserve unrelated changes and keep credentials out of commits and tool output.
